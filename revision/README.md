# Revision reproduction scripts

These scripts reproduce the corrected results reported in the revised manuscript
**"Structured Parameterization and Crystallographic Symmetry in Low-Complexity
Crystal-Property Neural Networks"** (Computational Materials Science,
COMMAT-D-26-03017R1). They supersede the earlier `validation/exp_crystal_energy.py`.

## Files

| File | Purpose |
|---|---|
| `exp_revision.py` | Corrected (coordinate-based, permutation-invariant) comparison: StandardMLP / WideMLP / OrbitMLP-pointgroup / StructMLP / OrbitMLP-O_h / GeoBinsMLP / RandomMLP; per-crystal-system and per-symmetry-level MAE; paired bootstrap + Wilcoxon; permutation-invariance test. Writes `revision_results.json`. |
| `exp_revision2.py` | Strict space-group-holdout transfer (standard/wide/point-group) and a resource benchmark. Writes `revision_extra.json`. |
| `train_cgcnn_matched.py` | CGCNN under the same protocol (80/20 per seed, AdamW + cosine, 200 epochs) on the same 2,741 crystals. **Requires the external [`cgcnn`](https://github.com/txie-93/cgcnn) package** and the crystal-set CIFs (not shipped here due to size). Writes `cgcnn_matched.json`. |

## Data note

The processed 2,741-crystal dataset (`crystal_data_decisive.pkl`) is generated by the
Materials Project query in `exp_revision.py`/`exp_revision2.py`; the scripts load the
cached pickle at `E:\operator\crystal_data_decisive.pkl`. The dataset is not committed
here due to size. Runs on a single RTX 4060 with PyTorch 2.x / CUDA 12.x.

## Results (formation energy, eV/atom, 3 seeds)

- StandardMLP 0.1898, WideMLP 0.0864 (+54%), OrbitMLP-pointgroup 0.1714 (+9.7%),
  StructMLP 0.2121, OrbitMLP-O_h 0.2792 (−47%), GeoBinsMLP 0.2597, RandomMLP 0.3745
- Matched-protocol CGCNN 0.0723 ± 0.0032
- Grid-collision fraction 74.2% (2,035/2,741); permutation invariance max |Δ| < 1e-6
